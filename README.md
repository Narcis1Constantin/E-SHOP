# Smart Depot

Full-stack e-commerce web application for selling home appliances.

**Live demo:** https://smart-depot.vercel.app/

## Features
- User authentication (JWT)
- Product listing, search and filters
- Shopping cart and checkout
- Orders, returns and reviews
- Multiple payment methods (cash, card, financing)
- Admin panel
- AI chatbot support
- Email notifications and PDF invoices

## Tech Stack
**Frontend:** React  
**Backend:** Node.js, Express  
**Database:** PostgreSQL
